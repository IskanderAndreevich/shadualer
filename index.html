mt19937_64
Справка: Seed, авторасчёт n = n₁ + n₂ и формат .txt файла нажмите, чтобы развернуть
Seed (зерно генератора): задаёт начальное состояние 64-битного Вихря Мерсенна (mt19937_64). При одинаковом Seed > 0 веб-версия, C++ ядро и Python-приложение генерируют идентичные данные. Значение 0 выбирает случайное зерно.
Авторасчёт n = n₁ + n₂: укажите общее n и одно из полей (n₁ или n₂), оставив второе пустым — оно вычисляется автоматически.
Формат файла (.txt): логические блоки разделяются пустой строкой (без заголовков и комментариев). Пары длительностей допускается записывать в столбик или в строчку через пробел/запятую. Порядок блоков:
  1. Требования Типа 1 (пары a_j b_j)
  2. Перестановка π₁ (символ «-» подставит естественный порядок 1..n₁)
  3. Требования Типа 2 (пары c_j d_j, или «-» при отсутствии)
  4. Перестановка π₂
  5. Требования Типа 3 (p_j) — необязательно
  6. Требования Типа 4 (q_j) — необязательно
